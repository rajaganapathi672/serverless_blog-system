# Technical Architecture

## Infrastructure Overview
The platform follows a completely serverless model to ensure high availability and cost efficiency.

### 1. Frontend Layer
- **Hosting**: Amazon S3 (Static Website Hosting).
- **Distribution**: Amazon CloudFront (CDN) with OAC for secure, global delivery.
- **Framework**: React 18 with Vite for fast builds and optimized performance.

### 2. API Layer
- **Gateway**: Amazon API Gateway (REST API).
- **Compute**: AWS Lambda (Node.js 18).
- **Security**: Cognito User Pool Authorizer for Admin routes.

### 3. Data Layer
- **Primary Database**: Amazon DynamoDB.
- **Design Pattern**: Single-Table Design.
- **Secondary Access**: GSI1 for the Public Feed (sorted by Date).

### 4. Storage Layer
- **Media**: Amazon S3 bucket for user-uploaded images.
- **Upload Flow**: Pre-signed URLs generated by Lambda for direct-to-S3 uploads.

## Data Flow
1. **Client** requests a page → Served by **CloudFront**.
2. **Client** calls API → Authenticated by **Cognito** (if Admin).
3. **API Gateway** triggers **Lambda**.
4. **Lambda** reads/writes to **DynamoDB**.
5. **Response** returned to Client via API Gateway.
