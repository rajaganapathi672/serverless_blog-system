# Project Roadmap

## 🎯 Phase 1: Current Release (MVP)
- [x] Basic Post CRUD (Create, Read, Update, Delete).
- [x] Public Post Feed and Detail view.
- [x] Admin Login with Cognito.
- [x] Simple Comment system.
- [x] Image upload via pre-signed URLs.

## 🚀 Phase 2: Enhanced Features
- [ ] **SEO Optimization**: Server-Side Rendering (SSR) for blog posts.
- [ ] **Search**: Integrate Amazon OpenSearch for full-text content search.
- [ ] **Comments Management**: Admin interface to moderate comments.
- [ ] **Analytics**: Track view counts and user engagement.

## 🛡 Phase 3: Enterprise Grade
- [ ] **Multi-Author Support**: Role-based access control (RBAC) for guest authors.
- [ ] **CI/CD Pipeline**: GitHub Actions for automated testing and deployment.
- [ ] **Domain Management**: Route 53 integration for custom domains.
- [ ] **Newsletter**: AWS Pinpoint or SES integration for subscriber updates.
